# チェックカレンダー (Check Calendar)

Google カレンダー風の洗練されたUIに、ToDoチェックリスト機能を統合したモダンなカレンダーWebアプリケーションです。

---

## ✨ 追加されたカレンダー機能一覧

### 1. 動的な日付・月計算 & ナビゲーション
- **前月・次月（`<` `>`）ボタン**: 年月をシームレスに切り替え。月末・月初や曜日の自動計算に対応。
- **「今日」ボタン**: ワンクリックで現在（基準日: 2026年11月11日）に素早く復帰。
- **ミニカレンダー連動**: サイドバーの日付クリックでメインカレンダーがその月に連動ジャンプ。

### 2. 予定・チェック項目（ToDo）の作成・編集・削除
- **日付マスをクリック**: その日付を選択して新規作成モーダルが立ち上がります。
- **「+ 作成」ボタン**: サイドバーからワンクリックで作成モーダルを表示。
- **カラーパレット選択**: ブルー、グリーン、レッド、イエロー、パープルから自由にタグカラーを選択可能。
- **編集・削除**: 登録済みのイベントをクリックしてタイトルや日付の修正、または削除ができます。

### 3. 「チェックカレンダー」ならではのToDoチェック機能
- **完了・未完了のワンタップ切替**: カレンダー上の各タスクのチェックボックスをクリックすると、打ち消し線が入り完了状態にできます。
- **サイドバーのタスク進捗バー**: 完了率をリアルタイムにプログレスバーで可視化。

### 4. 表示ビュー切り替え（月 ▾ ドロップダウン）
- **月表示**: Googleカレンダー風のマンスリービュー。
- **チェック一覧表示**: 登録したすべてのToDo項目を一覧で確認・チェック可能。

### 5. 検索機能
- ヘッダーの虫眼鏡アイコンをクリックすると検索窓が開き、予定やタスクのタイトルをリアルタイム絞り込み検索できます。

### 6. データの自動保存（LocalStorage）
- ブラウザをリロードしても、追加した予定やタスクの完了状態が保持されます。
- 設定（歯車アイコン）からいつでも初期状態にリセット可能です。

---

## 🚀 起動方法

### 方法 1: ダブルクリックで即座に試す
フォルダ内の [preview.html](preview.html) をお好みのブラウザ（Chrome, Edge等）でダブルクリックして開くだけですぐにお使いいただけます。

### 方法 2: Vite 開発サーバーで動かす
```bash
npm run dev
```
ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開きます。
