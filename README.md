# チェックカレンダー (Check Calendar)

Google カレンダー風の洗練されたUIに、**「できた度合（0〜100%）の入力」**、**「タグカラー自由設定（プリセット＆カスタムピッカー）」**、日本の祝日自動計算、**「全体の目標 × 1日に達成する目標」**、**「達成度に応じた黄緑ヒートマップ（月表示・年間表示草生やし）」**、そして**「ダークモード / ライトモード切り替え機能」**を備えたモダンなWebアプリケーションです。

---

## 🎯 目標・やることの操作（ワンクリック編集 ＆ ダブルクリック進捗入力）
- **ワンクリックで編集**:
  - カレンダー上の目標・やることを**ワンクリック**すると、目標名・ノルマ・期間・タグ・カラーを変更できる「目標・やることの編集」画面が開きます。
- **タグカラーの自由な変更**:
  - 8色の鮮やかなプリセットカラー（青・緑・赤・黄・紫・オレンジ・ピンク・シアン）に加え、**カラーピッカー（🎨）で好きな色を自由自在に選択・変更可能**です。
  - やること・目標カードは設定したタグカラーの鮮やかな一定の色で表示されます。
  - 同じタグを持つ目標のカラーも一括同期され、サイドバーのタグ一覧にもタグカラーが美しく反映されます。
- **ダブルクリックで進捗入力**:
  - 目標・やること、または右端の達成度バッジを**ダブルクリック**（またはバッジをクリック）すると、「できた度合（達成度）の入力」モーダルが開き、0〜100%の達成度を素早く入力できます。
  - 各タスク右端に `0%` 〜 `100%` のバッジが表示され、視覚的に進捗が一目でわかります。

---

## 🌙 ダークモード / ライトモード切り替え機能
- ヘッダー右上の **太陽（☀️）/ 月（🌙）アイコン** をワンクリックするだけで、背景色を黒基調のダークテーマと白基調のライトテーマに瞬時に切り替えられます。
- **ダークテーマ時の最適化**:
  - 背景やサイドバー、モーダルが目に優しいダークグレー（`#121212`, `#1e1e1e`, `#282a2d`）に変化。
  - 達成度ヒートマップ（草生やし）も、GitHubのダークテーマのように濃いダークグリーン〜エメラルドグリーン（`#0e4429`, `#238636`, `#2ea043`）へと切り替わり、暗所でもコントラスト高く美しく映えます。
- **設定の永続化**: テーマの選択状態は `localStorage` に保存され、ページをリロードしても前回のテーマが維持されます。

## ✨ 達成度黄緑ヒートマップ機能（GitHub草生やし風）

### 1. 月表示（マンスリー）での段階的黄緑化
- 各タスクのできた度合に応じて、**その日のマスの背景色が黄緑色にグラデーション変化**します。
  - **100%達成！**: 鮮やかな黄緑色（`#d9f99d`）＋ 右上に星マーク（🌟）＋ 達成バッジ（`100%`）
  - **70%以上**: 明るい黄緑色（`#ecfccb`）
  - **30%以上**: ほんのり淡い黄緑色（`#f7fee7`）
  - **0%（未着手）**: 通常の白背景
- 毎日タスクを達成していくことで、カレンダーが黄緑色で埋まり、継続と努力が視覚的に実感できます。

### 2. 年間表示（Year View）での草生やし年間ヒートマップ
- 年間表示（1月〜12月の一覧ビュー）に切り替えた際も、**各日付の丸いセルがその日の達成度に応じて黄緑色に色づきます**！
  - 100%達成日は鮮やかな黄緑バッジ（`#84cc16`）
  - 達成度に応じて滑らかに濃淡が変化
- 1年間の学習やタスクの継続状況（習慣トラッカー・草生やし）を一目で俯瞰・振り返ることができます。

### 3. サイドバーのミニカレンダー連動
- サイドバー内のミニカレンダーでも、達成度が高い日付が黄緑色にハイライトされます。

## 🚀 起動方法

### 方法 1: ブラウザで直接開く
プロジェクト内の [index.html](index.html) をブラウザで開くだけですぐにお使いいただけます。

### 方法 2: Vite 開発サーバーで動かす
```bash
npm run dev
```
ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開きます。
