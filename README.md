# チェックカレンダー (Check Calendar)

Google カレンダー風の洗練されたUIに、ToDoチェック機能・日本の祝日完全自動計算、そして**「全体の目標 × 1日に達成する目標」**の2段階目標管理を備えたモダンなWebアプリケーションです。

---

## ✨ 2段階の目標設定機能

### 1. 全体の目標（ゴール・大目標）
- 期間全体を通して達成したい最終成果・ゴールを設定します。
- 例: `英単語ターゲット1900 完走`、`基本情報技術者 午前過去問 3年分制覇`、`問題集を1冊解き切る`

### 2. 1日に達成する目標（日々のノルマ・小目標）
- カレンダーの各マス（日付ごと）に直接表示され、毎日クリアしていく具体的なアクションです。
- 例: `1日50単語暗記＆確認テスト`、`午前過去問 20問解答＆見直し`、`1日15ページ進める`

### 3. 日々の達成チェック & プログレスバー
- カレンダーの各日付マスにあるチェックボックスをクリックすると、**その日の「1日に達成する目標」が達成済み（打ち消し線）**になります。
- 期間中の進捗がリアルタイムに計算され、チェック一覧では「3 / 5 日完了 (60%)」のようにプログレスバーで可視化されます。
- サイドバー下部には、日々の目標達成日数（例: `2 / 10 日`）の炎アイコン付き進捗バーが表示されます。

## 🚀 起動方法

### 方法 1: ダブルクリックで即座に試す
フォルダ内の [preview.html](preview.html) をブラウザでダブルクリックして開くだけですぐにお使いいただけます。

### 方法 2: Vite 開発サーバーで動かす
```bash
npm run dev
```
ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開きます。
