# チェックカレンダー (Check Calendar)

Google カレンダー風の洗練されたUIに、ToDoチェックリスト・日本の祝日自動計算、そして**「やること（勉強など）・タグ・やる期間表示」**を統合したモダンなWebアプリケーションです。

---

## ✨ 新機能: やること・勉強・タグ・やる期間の管理

### 1. やること・勉強の追加モーダル
- **やること（内容）**: 「数学のワーク」「英単語暗記」「資格試験過去問」などを自由に入力。
- **タグ（カテゴリー）**:
  - プリセットタグ: `📚 勉強`, `💼 仕事`, `🏃 運動`, `📖 読書`, `🎨 趣味`
  - 自由なテキスト入力で独自タグの作成も可能。
- **やる期間（開始日 〜 終了日）**:
  - 単日だけでなく、数日〜数週間にわたる期間を指定可能。
  - 何日間のやる期間かを「○日間」とリアルタイムにプレビュー表示。
- **タグカラー**: ブルー、グリーン、レッド、イエロー、パープルから自由に設定。

### 2. カレンダー上での期間バー（帯状）表示
- 複数日にわたるやることは、Googleカレンダーのように**帯状の期間バー**として連続表示されます。
- 開始日には左角丸と期間日数バッジ（例: `5日間`）、中間日はフラット、終了日には右角丸で美しくレンダリング。
- 各バーに `#勉強` などのタグバッジとチェックボックスが付きます。

### 3. タグ別絞り込みフィルター
- サイドバーの「タグで絞り込み」ボタン（`すべて`、`#勉強`、`#仕事` など）をクリックすると、選んだタグのやることだけをカレンダー上に一発絞り込み表示できます。

### 4. チェック（完了/未完了）連動 & 進捗バー
- カレンダー上やチェック一覧からワンクリックでタスクの達成（打ち消し線）を切り替え可能。
- サイドバーの達成率プログレスバーがリアルタイムに更新されます。

## 🚀 起動方法

### 方法 1: ダブルクリックで即座に試す
フォルダ内の [preview.html](preview.html) をブラウザでダブルクリックして開くだけですぐにお使いいただけます。

### 方法 2: Vite 開発サーバーで動かす
```bash
npm run dev
```
ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開きます。
