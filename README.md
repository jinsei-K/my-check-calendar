# チェックカレンダー (Check Calendar)

Google カレンダー風の洗練されたUIに、ToDoチェックリスト機能と日本の祝日完全対応を備えたモダンなカレンダーWebアプリケーションです。

---

## ✨ 機能一覧

### 1. 日本の祝日・振替休日の完全自動計算 & 独自記念日の追加
- **国民の祝日を完全網羅**:
  - 元日、成人の日、建国記念の日、天皇誕生日、春分の日、昭和の日、憲法記念日、みどりの日、こどもの日、海の日、山の日、敬老の日、秋分の日、スポーツの日、文化の日、勤労感謝の日
- **振替休日・国民の休日の自動判定**:
  - 祝日が日曜日に重なった場合の翌日以降の振替休日、および祝日に挟まれた国民の休日を自動算出。
- **年中行事対応**:
  - 11月15日の「七五三」など年中行事にも対応。
- **祝日一覧ビュー**:
  - 右上のドロップダウンから「祝日一覧」を選択すると、その年のすべての祝日と日付をカード形式で一覧できます。
- **独自祝日・記念日の追加**:
  - サイドバーの「祝日・記念日を追加」ボタンから、会社の創立記念日や個人の記念日などを緑色バッジで自由に追加可能。
- **赤色ハイライト**:
  - 日曜日および祝日の日付数字は赤色で視認性高く表示されます。

### 2. 表示ビューの切り替え（「月 ▾」ドロップダウン）
- **月表示（Month View）**: Googleカレンダー風のマンスリービュー。
- **年表示（Year View）**: 1月〜12月を4列×3行で俯瞰できる年間カレンダー。月や日付をクリックすると月表示にジャンプ。
- **祝日一覧ビュー**: 年間の祝日・記念日を一覧確認。
- **チェック一覧（ToDo）**: 登録したToDoタスクの達成状況を一括管理。

### 3. 動的ナビゲーション
- 前後ボタン（`<` `>`）: 月表示では月送り、年表示では年送り。
- 「今日」ボタン: 基準日（2026年11月11日）にワンクリックで復帰。
- ミニカレンダー連動: サイドバー内の日付クリックで該当年月にジャンプ。

### 4. チェック（ToDo）機能
- 各タスクのチェックボックスをクリックすると、打ち消し線が入って完了状態に。
- サイドバーの進捗バーでタスクの達成率をリアルタイムに可視化。

### 5. 検索 & データ永続化
- 虫眼鏡アイコンから、予定・タスク・祝日をリアルタイム検索。
- LocalStorageによりリロード後もデータが保持されます。

## 🚀 起動方法

### 方法 1: ダブルクリックで即座に試す
フォルダ内の [preview.html](preview.html) をお好みのブラウザ（Chrome, Edge等）でダブルクリックして開くだけですぐにお使いいただけます。

### 方法 2: Vite 開発サーバーで動かす
```bash
npm run dev
```
ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開きます。
