# チェックカレンダー (Check Calendar)

Google カレンダー風のモダンなUIを持つカレンダーWebアプリケーションです。

## 特徴・再現ポイント
- **添付画像（2026年11月）のUIを忠実に再現**:
  - 左上メニューアイコン（ハンバーガーメニュー ＋「メニュー」表記）
  - サイドバー展開時の「✕」閉じるボタン、「+ 作成 ▾」ピル型ボタン
  - サイドバー内の「2026年 11月」ミニカレンダー（1日選択ハイライト、11日の今日ハイライト）
  - 「今日」ボタン、前後月ナビゲーション（`<` `>`）、年月表示（`2026年 11月`）
  - 右側アイコン群（検索、サポート/？、設定/歯車、「月 ▾」ドロップダウン）
  - メインカレンダーエリア：角丸の白カードコンテナ、薄いグリッド線
  - 日付表示（月の初日の「11月1日」「12月1日」表記、現在の「11」青丸バッジ）
  - 祝日・イベントバッジ（緑色の「文化の日」「七五三」「勤労感謝の日」）
  - サイドバーの開閉トグル（画像の左側・右側の両方の状態を完全再現）

## 起動方法

### 方法 1: ダブルクリックで即座に確認
フォルダ内の [preview.html](preview.html) をブラウザで直接開くだけで確認できます。

### 方法 2: Vite 開発サーバーで起動
```bash
npm install
npm run dev
```
ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開きます。
